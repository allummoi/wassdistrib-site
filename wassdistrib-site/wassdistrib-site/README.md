# Site WASS DISTRIB — ALLUM'MOI

Site vitrine du mini briquet USB-C ALLUM'MOI, distribué par WASS DISTRIB.

- `index.html` : le site complet (une seule page).
- `favicon.png` : l'icône affichée dans l'onglet du navigateur.
- `images/` : les logos en haute qualité (non utilisés par la page, gardés ici pour les retrouver facilement).

Hébergement : Netlify. Le formulaire « Recevoir la grille tarifaire » utilise Netlify Forms.
